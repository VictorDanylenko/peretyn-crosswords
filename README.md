# Перетин

Перетин — україномовний конструктор кросвордів, створений на прохання студентів КСУБГ.

[Створити кросворд](https://peretyn-crosswords.vercel.app/)

Введіть назву, додайте щонайменше дві пари «слово й запитання» зі спільною літерою та натисніть **Згенерувати сітку**. Попередній перегляд показує розташування слів, номери й запитання. **Експорт у PDF** створює аркуші A4 для друку та, за бажанням, окремий файл із ключем.

## Робота зі словником

- Чернетка та остання актуальна сітка зберігаються в цьому браузері. Після редагування слів згенеруйте сітку повторно.
- Файл JSON містить назву `title` і масив `entries` із полями `word` та `clue`. Можна зберегти як готовий словник, так і чернетку.
- «Новий кросворд» відкриває порожній редактор після підтвердження.
- Генератор підтримує 2–60 слів завдовжки 2–24 літери. Він шукає перетини на однакових літерах та перевіряє сусідні клітинки. Якщо весь набір розмістити не вдалося, редактор покаже нерозміщені слова.
