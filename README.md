# Перетин

Україномовний конструктор кросвордів. Введіть назву, додайте щонайменше дві пари «слово й запитання» зі спільною літерою та натисніть **Згенерувати сітку**. Попередній перегляд показує розташування слів, номери й запитання. **Експорт у PDF** створює аркуші A4 для друку та, за бажанням, окремий файл із ключем.

## Робота зі словником

- Чернетка та остання актуальна сітка зберігаються в цьому браузері. Після редагування слів згенеруйте сітку повторно.
- Файл JSON містить назву `title` і масив `entries` із полями `word` та `clue`. Можна зберегти як готовий словник, так і чернетку.
- «Новий кросворд» відкриває порожній редактор після підтвердження.
- Генератор підтримує 2–60 слів завдовжки 2–24 літери. Він шукає перетини на однакових літерах та перевіряє сусідні клітинки. Якщо весь набір розмістити не вдалося, редактор покаже нерозміщені слова.

## Запуск

Відкрийте **peretyn.html** для автономної роботи або виконайте `npm run dev` і перейдіть на http://127.0.0.1:5188/. Зовнішніх залежностей для роботи застосунку немає.

Змінюйте файли в `src/`. Команда `npm run build` оновлює статичну збірку в `dist/` та автономний HTML із вбудованим логотипом і фавіконом. Команда `npm test` перевіряє генератор і збірку з чистих джерел.

## Vercel

Використовуйте папку `crossword-studio` як Root Directory, якщо в репозиторії кілька проєктів. Для окремого репозиторію застосунку коренем є `.`. У `vercel.json` задано Framework Preset **Other**, Build Command **npm run build** і Output Directory **dist**. Локальний сервер запускається лише під час розробки.

В архіві **peretyn-vercel.zip** джерела лежать у корені. Для публікації розпакуйте архів і розгорніть ці джерела через ваш проєкт Vercel.
